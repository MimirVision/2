# Personvernerklæring for Flipp

*Sist oppdatert: [DATO]. Ansvarlig: [DITT NAVN / FIRMA], [E-POST].*

## Hva vi behandler
- **Bilder du velger å skanne.** Bildet sendes kryptert til vår server og videre til vår KI-leverandør (Anthropic) kun for å lage verdsettingen og annonseteksten. Vi lagrer ikke bildene på våre servere. Bildene lagres bare lokalt på telefonen din, og slettes når du sletter tingen eller appen.
- **Tekst du skriver inn** (valgfrie notater om tingen) behandles på samme måte som bildet.
- **Et anonymt bruker-ID og kjøpshistorikk** fra App Store, via vår betalingsleverandør RevenueCat, for å vite om du har et aktivt abonnement. Vi teller antall skann per bruker-ID og per IP-adresse per døgn for å hindre misbruk. Tellerne slettes automatisk etter ca. ett døgn (gratisskann lagres til appen ikke lenger brukes).
- **Lageret ditt** (ting, priser, salg) lagres bare lokalt på enheten din.

Vi bruker ikke sporing på tvers av apper, selger ingen data og viser ikke reklame.

## Underleverandører
- Anthropic PBC (KI-analyse av bilder): anthropic.com/legal/privacy
- RevenueCat Inc. (abonnementer): revenuecat.com/privacy
- Cloudflare Inc. (server og drift): cloudflare.com/privacypolicy
- Apple (betaling via App Store)

## Dine rettigheter
Du kan be om innsyn, retting eller sletting ved å kontakte [E-POST]. Siden vi ikke lagrer bilder eller navn, har vi som regel bare det anonyme bruker-ID-et og abonnementsstatusen. Du kan klage til Datatilsynet.

## Abonnement
Abonnementet fornyes automatisk og belastes Apple-kontoen din. Det kan sies opp når som helst i App Store-innstillingene, senest 24 timer før perioden fornyes.
